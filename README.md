# Sleep Score in E♭

A week of sleep stages played as music. Each night is cut into even steps, each step takes one sleep stage, and each stage sings in its own register over an E♭ drone.

Live: https://harmonicsystems.github.io/sleep-score/

One static `index.html`, Web Audio only, no build step. Stage times were traced by eye from a Health screenshot, so they are close, not exact.
